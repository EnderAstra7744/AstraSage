# Chose-Stayle

AstraSage için renk teması ve banner özelleştirme paketi.

## Kullanım

chose-stayle yazarak menüyü açın.

## Özellikler

- 6 farklı renk teması (yeşil, mavi, kırmızı, sarı, mor, turkuaz)
- 4 farklı banner stili (klasik, minimal, bold, ascii)
- Canlı önizleme

## Tema Dosyası

assets/astrasage_theme.json
