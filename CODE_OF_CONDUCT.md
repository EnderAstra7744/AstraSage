# Code of Conduct

## Our Goal

The AstraSage community should be a friendly, respectful and constructive
environment for everyone.

## Expected Behavior

Contributors are expected to:

- Be respectful.
- Communicate constructively.
- Accept reasonable criticism.
- Focus on improving the project.
- Respect other contributors.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment
- Threats
- Personal attacks
- Hate speech
- Deliberate disruption
- Sharing private information without permission

## Project Discussions

Technical disagreements are normal.

Discuss the technical problem rather than attacking the person.

## Enforcement

Project maintainers may remove comments, reject contributions or take other
reasonable actions when this Code of Conduct is violated.

## Scope

This Code of Conduct applies to project discussions, issues, pull requests
and other official AstraSage community spaces.
