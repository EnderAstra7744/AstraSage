# Security Policy

## Reporting a Security Issue

If you discover a security vulnerability in AstraSage, please report it
responsibly.

Do not publicly disclose a serious vulnerability before there is an
opportunity to investigate and fix it.

## What to Include

Please provide:

- A description of the vulnerability
- Steps to reproduce the issue
- Affected component or file
- Possible impact
- Any relevant logs or error messages

## Supported Versions

Security fixes will generally target the latest development version of
AstraSage.

Older versions may not receive security updates.

## Security Philosophy

AstraSage is intended to be a useful and extensible terminal environment.

Security-related functionality should be designed with user consent,
transparency and system safety in mind.

Do not use AstraSage to access systems or data without authorization.
