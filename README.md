# AstraSage

AstraSage is an open-source, customizable terminal environment designed
primarily for developers and terminal users.

## Features

- Custom terminal commands
- Customizable terminal themes
- Library management
- System information
- Neofetch-style system information
- Command autocomplete
- Alias support
- Multiple distribution support
- Android/Termux compatibility
- Developer-oriented tools
- Extensible architecture

## Supported Platforms

AstraSage is primarily designed for:

- Android
- Termux
- Linux
- Raspberry Pi

Other platforms may work depending on system configuration.
