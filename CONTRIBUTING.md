# Contributing to AstraSage

Thank you for your interest in contributing to AstraSage.

AstraSage is an open-source project and contributions are welcome.

## Before Contributing

Please make sure that:

- Your change is related to AstraSage.
- Your code is understandable.
- Existing functionality is not unnecessarily broken.
- You have tested your changes before submitting them.

## Bug Reports

If you find a bug, please provide:

- A clear description of the problem
- Steps to reproduce it
- Expected behavior
- Actual behavior
- Operating system
- Python version
- Relevant error messages

## Feature Requests

For new features, explain:

- What the feature does
- Why it would be useful
- How it could work
- Whether it affects existing functionality

## Pull Requests

When creating a pull request:

1. Explain what you changed.
2. Explain why you changed it.
3. Test the changes.
4. Keep unrelated changes out of the pull request.

## Code Style

Try to keep the existing AstraSage coding style consistent.

Use clear variable and function names.

Avoid unnecessary complexity.

## Security

Do not submit code that intentionally damages systems, steals data,
bypasses security controls, or performs unauthorized actions.

If you discover a security vulnerability, report it privately rather than
publicly exposing the vulnerability.

## Thank You

Every contribution helps AstraSage improve.
